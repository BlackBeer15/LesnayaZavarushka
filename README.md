# Лесная Заварушка — LAN-мультиплеерная охота

3D-игра на **Godot 4.7.2** с мультиплеером по локальной сети. При первом запуске
`run.bat` сам скачает портативный движок в папку `_engine` (в репозиторий он не
входит из-за размера). Устанавливать ничего вручную не нужно.

## Запуск

**На первом компьютере (хост):**

1. Запустить `run.bat`.
2. Ввести имя и нажать **«СОЗДАТЬ СЕРВЕР»**.
3. Сообщить друзьям свой локальный IP (например `192.168.1.10`).

**На остальных компьютерах (клиенты):**

1. Запустить `run.bat`.
2. Ввести имя, в поле **«IP сервера»** указать IP хоста.
3. Нажать **«ПОДКЛЮЧИТЬСЯ»**.

Игра использует **UDP-порт 7777**. Если клиенты не подключаются — разрешите
этот порт в брандмауэре Windows на хосте.

Быстрый старт из командной строки:

```
run.bat --host
run.bat --join 192.168.1.10
```

## Сборка релиза

```
powershell -ExecutionPolicy Bypass -File build_release.ps1
```

Скрипт сам скачает шаблоны экспорта Godot (≈1.3 ГБ, только при первой сборке),
соберёт `build/windows/LesnayaZavarushka.exe` и, если установлен Inno Setup
(`iscc` в PATH), сделает `build/LesnayaZavarushka_setup.exe`. Настройки сборки
лежат в `export_presets.cfg` и `installer.iss`. Движок и шаблоны в репозиторий
не попадают.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | `W A S D` |
| Обзор | Мышь |
| Выстрел | ЛКМ |
| Прицеливание | ПКМ |
| Перезарядка | `R` |
| Тип патронов | `Q` |
| Спринт | `Shift` |
| Присед | `Ctrl` |
| Прыжок | `Пробел` |
| Камера 1-е / 3-е лицо | `V` |
| Казино (открыть/закрыть) | `E` (или кнопка «Закрыть» мышью) |
| Крутить слот (10 монет) | `F` (или кнопка мышью) |
| Инвентарь | `Tab` |
| Сменить оружие | `1`–`8` |
| Меню / пауза | `Esc` |

В казино и инвентаре курсор освобождается и всем управляет мышь. В инвентаре
оружие перетаскивается между ячейками — порядок хранится на хосте и виден всем
игрокам.

В главном меню (и в меню паузы по `Esc`) есть ползунок **«Громкость звука»**.
Значение применяется сразу ко всем звукам и сохраняется в `user://settings.cfg`.

На время разработки все пять оружий выдаются сразу (слоты `1`–`5`): казино
пока не нужно для их получения. Убрать это можно в `GameData.starter_inventory()`.

## Геймплей

- Большая процедурная карта 360×360 с разными биомами: лес, поляны, скалы,
  болото, озеро и поляна с казино. Рельеф генерируется по шуму, деревья и камни
  рисуются `MultiMesh`-ами.
- Травоядные (заяц, олень, кабан) убегают от игроков, хищные (лиса, волк,
  медведь) охотятся и наносят урон.
- У каждого зверя есть **скрытая способность**, включающаяся в случайный момент:
  фантомный рывок, дубовый панцирь, бешеный таран, лисьи призраки, кровавая луна,
  берсерк. Во время действия зверь подсвечивается и показывает название способности.
- Попадание в **глаза или сердце** считается критическим: время замедляется,
  камера следует за пулей, а туша разрывается на процедурные кровавые обломки
  (брызги крови, конечности, следы на земле). За критическое попадание падает
  больше монет.
- С убитых зверей выпадают монеты. У игрового автомата в казино монеты
  обмениваются на оружие пяти уровней редкости: от «Егерь П-9» до легендарного
  «Солнце Леса». Чем лучше оружие, тем ниже шанс выпадения (50 / 28 / 15 / 6 / 1 %).
  Два одинаковых символа дают монеты, три — оружие (или монеты, если оно уже есть).
- Звуки выстрелов для каждого оружия лежат в корне проекта (`Pistol.mp3`,
  `revolver.mp3`, `shotgun.mp3`, `sniper.mp3`, `laser.mp3`).
- Стрельба: прицеливание ПКМ, отдача и разброс, дым, гильзы, вспышка, анимация
  затвора и магазина, цифры урона и тряска камеры. Выстрел слышат звери.
- Три типа патронов, аптечки и патроны на карте, спринт с выносливостью, присед,
  плавание, кровотечение. Уязвимые точки подсвечиваются: глаза ослепляют, шея
  парализует, сердце убивает мгновенно.

## Как устроен мультиплеер

- Встроенный high-level multiplayer Godot (ENet). Хост — авторитет: у него
  живёт ИИ зверей, урон, монеты, выпадение предметов и казино.
- Клиенты управляют своим игроком локально и отправляют позицию/угол хосту
  (20 раз в секунду); хост рассылает снапшоты игроков и зверей.
- Выстрел отправляется хосту как RPC, хост делает авторитетный рейкаст и
  рассылает результат: попадание, критический ли это урон, где появились кровь и монеты.
- Кинематографичный слоу-мо включается только у того игрока, который попал.

Детальные процедурные модели оружия (пистолет, револьвер, дробовик, снайперская
винтовка, плазменный автомат) — без внешних ассетов, со всеми мелкими деталями.
Отдельные процедурные кисти в от первого лица по-прежнему не добавляются (они
мешали обзору); в третьем лице модель игрока имеет простые руки, поворачивается
вместе со взглядом и анимирует шаги. Хост видит подключившихся игроков.

Все эффекты, модели зверей, ландшафт и звуки генерируются кодом — внешних
ассетов нет.

## Отладочные флаги (для проверки сети)

```
run.bat --host --debug-state
run.bat --join 127.0.0.1 --debug-state --test-spin
run.bat --host --debug-state --test-fire
run.bat --host --test-casino
run.bat --host --test-weapon sniper
```

`--debug-state` печатает состояние игрока в консоль, `--test-spin` делает
одно вращение автомата, `--test-fire` заставляет хоста стрелять в сердце
ближайшему зверю каждые 2 секунды, `--test-casino` открывает казино,
`--test-weapon` позволяет посмотреть модель нужного оружия.

Все флаги `--debug-state` и `--test-*` работают только в debug-сборке —
в релизной их проверка отключена через `OS.is_debug_build()`. Флаги `--host`
и `--join` остаются доступны в любой сборке.

Игра всегда запускается в полноэкранном режиме.

## Структура

```
project.godot
main.tscn
scripts/
  main.gd          меню, сцена, RPC-обработчики, киллкам
  network.gd       ENet, авторитет хоста, все RPC
  world.gd         рельеф, биомы, лес, казино
  player.gd        управление, стрельба, камера, состояние
  animal.gd        ИИ, способности, уязвимые точки
  effects.gd       кровь, обломки, монеты, трассеры
  casino.gd        слот-автомат
  hud.gd           HUD и мини-карта
  game_state.gd    глобальные ссылки
  sfx.gd           процедурные звуки
  settings.gd      громкость, сохранение настроек
  constants.gd     баланс и данные
_engine/           портативный Godot 4.7.2
```
